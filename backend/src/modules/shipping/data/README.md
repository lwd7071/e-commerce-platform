# Vietnam administrative address data

`vn-admin-catalog.json` contains the 34 province/city and 3,321 ward/commune identifiers used by buyer and seller address forms. It is bundled locally so address selection does not depend on a third-party service at runtime.

Attribution: **Open Admin Data — Vietnam Administrative Divisions**, licensed under CC-BY-4.0. Source dataset and citation: https://github.com/open-admin-data/vietnam-administrative-divisions. The code list follows Vietnam Decision 19/2025/QĐ-TTg; the official government publication is https://xaydungchinhsach.chinhphu.vn/bang-danh-muc-va-ma-so-cua-34-tinh-thanh-moi-cac-don-vi-hanh-chinh-cap-xa-moi-11925070418263625.htm.

The checked-in catalog is a reduced projection of the province and ward source files. Update it only from a reviewed source revision; retain source attribution and verify that counts remain 34 and 3,321.
